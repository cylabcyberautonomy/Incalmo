# Actions
- `FindInformationOnHostWrapper` (find_information_on_host.py): Finds information on a host the attacker has already infected, including SSH configurations and critical data files. Example usage:

`FindInformationOnHostWrapper(ip_address: str)`

- `LateralMoveToHostWrapper` (lateral_move.py): Attempts lateral movement to a specific host using available techniques (credentials or exploits)

`LateralMoveToHostWrapper(source_ip_address: str, target_ip_address: str):`

- `ScanWrapper` (scan.py): Performs network and host scans to discover information about the target environment

`ScanWrapper(scan_host_ip: str, ip_to_scan: str)`

- `ExfiltrateDataWrapper` (exfiltrate_data.py): Exfiltrates data from the host to the attacker's host. Intelligently reasons about the network to determine the exfiltration path.

`ExfiltrateDataWrapper(ip_address: str)`

- `EscelatePrivledgeWrapper` (escelate_privledge.py): Attempts to escalate privileges on a target host using available techniques.

`EscelatePrivledgeWrapper(ip_address: str)`
